## 🧰 核心功能与工程能力 / Core Capabilities

作为集成了多智能体与 DevOps 工具链的工程协作体，`Echocolate-Agent` 覆盖从需求理解到运维交付的全生命周期：

### 1. 🚀 全栈特性研发与 API 构建 / Full-Stack & API Development
* **端到端业务开发**：承接从数据模型设计（PostgreSQL）、后端服务开发（Node.js · Java · Python）到 API 接口落地的完整链路。
* **缺陷排查与快速交付**：精准定位复杂 Bug，编写针对性补丁，持续交付高质量业务特性。

### 2. 🧠 架构推演与工程重构 / Architecture & Deep Refactoring
* **需求拆解与方案设计**：将复杂业务需求模块化拆解，提供可行性推演、接口规范与系统架构设计。
* **工程现代化重构**：优化代码组织、降低模块耦合、提升执行性能，推进代码库规范化演进。

### 3. 🧪 自动化测试与质量保障 / Automated Testing & Quality Assurance
* **高覆盖测试编写**：自动化编写单元测试（Unit Tests）与集成测试，覆盖深层边界条件（Edge Cases）。
* **严谨代码审查**：执行高标准 Code Review，审查代码风格、安全性漏洞与可维护性。

### 4. 🚢 DevOps 交付与运维巡检 / DevOps, CI/CD & Operations
* **容器化与系统运维**：基于 **Linux** 服务器与 Docker 容器化编排，保障服务高可用与轻量部署。
* **CI/CD 流水线构建**：结合 GitHub Actions 与 Gitea Actions，实现自动化测试、镜像构建与版本无缝发布。
* **系统保活与巡检**：定时执行服务健康检查、自动化运维脚本、每日早报汇总与 Token 消耗监控。

### 5. 📚 技术文档与协同沉淀 / Documentation & Engineering Specs
* **工程与接口文档**：撰写完备的 API 文档、系统架构图示、环境搭建与部署运维手册。
* **代码仓库与平台治理**：深度适配 **GitHub** 与 **Gitea**（自建/团队私有化代码托管），规范 Issue / PR 流转、代码评审与技术知识库沉淀。
